Grade 10 Mathematics class test: answers

Question 1
1.1 (2x + 3)(x - 4) = 2x² - 8x + 3x - 12 = 2x² - 5x - 12
1.2 x² - 9 is a difference of squares, so x² - 9 = (x - 3)(x + 3)
1.3 2x² + 7x + 3 = 2x² + 6x + x + 3 = 2x(x + 3) + 1(x + 3) = (2x + 1)(x + 3)
1.4 (2a³)² = 2² × a^(3x2) = 4a^6

Question 2
2.1 3x - 7 = 11 so 3x = 18 and x = 6
2.2 x² - 5x + 6 = 0 factorises as (x - 2)(x - 3) = 0 so x = 2 or x = 3
2.3 2x + 1 > 7 so 2x > 6 and x < 3
2.4 Adding the two equations gives 2x = 8 so x = 4, and then 4 + y = 7 so y = 3

Question 3
3.1 f(3) = 2(3) - 4 = 6 - 4 = 2
3.2 Let y = 0: 0 = 2x - 4 so x = 2, the x-intercept is (2; 0)
3.3 Let x = 0: y = 2(0) - 4 = -4, the y-intercept is (0; -4)
3.4 f(x) = 2x - 4 is in the form y = mx + c so the gradient is 2
3.5 g(-2) = (-2)² - 1 = 4 - 1 = 3

Question 4
4.1 sin θ = opposite/hypotenuse = 6/10 = 0,6
4.2 By Pythagoras, adjacent² = 10² - 6² = 100 - 36 = 64 so adjacent = 8 cm
4.3 tan θ = opposite/adjacent = 6/8 = 0,75
